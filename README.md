# 👨‍💻 Arun Trivedi - Personal Portfolio

Welcome to the repository of my personal portfolio website! This project is a fully responsive, interactive single-page application (SPA) designed to showcase my skills in Full Stack Web Development, Machine Learning, and Software Engineering.

**🔗 Live Demo:** [Click here to view my Portfolio](https://trivediarun446.github.io/Portfolio/) *(Update this link if your repo name is different)*

## 🚀 About The Project

As a B.Tech Computer Science student and a Machine Learning enthusiast, I built this portfolio from scratch to demonstrate my practical coding abilities. It serves as a digital resume highlighting my technical foundation in C/C++, Python, Database Management, and frontend web technologies.

### ✨ Key Features
*   **Fully Responsive Design:** Optimized for desktops, tablets, and mobile devices using CSS Grid, Flexbox, and Media Queries.
*   **Interactive UI/UX:** Smooth scrolling, hover effects, floating animations, and custom CSS variables for a cohesive blue-themed aesthetic.
*   **Dynamic Navigation:** JavaScript-powered navigation bar that dynamically highlights active sections as the user clicks.
*   **Dedicated Sections:**
    *   **About Me:** Academic background and current focus on AI & Data Science.
    *   **Technical Knowledge:** Core competencies (C/C++, Python, SQL, ML Algorithms, Web Dev, Git/GitHub).
    *   **Projects:** Highlighting real-world applications like my Python/SQLite *Expense Tracker*.
    *   **Internship:** Showcasing professional experience building platforms for an early-stage startup.

## 💻 Local Setup & Execution

To run this project locally on your machine, follow these simple steps:

1.  **Clone the repository:**
    \`\`\`bash
    git clone https://github.com/trivediarun446/Portfolio.git
    \`\`\`
2.  **Navigate to the project directory:**
    \`\`\`bash
    cd Portfolio
    \`\`\`
3.  **Run the application:**
    Simply open the \`index.html\` file in any modern web browser (Chrome, Edge, Firefox, etc.). No local server or build process is strictly required, though a tool like VS Code's *Live Server* extension is recommended for testing.
